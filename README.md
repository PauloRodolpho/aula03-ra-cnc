# Aula 03 — Manual Interativo de um Torno CNC em Realidade Aumentada

Projeto didático para ADS usando GitHub Pages, MindAR, A-Frame, HTML, CSS e JavaScript.

## Antes de publicar

1. Abra o compilador oficial de targets do MindAR: https://hiukim.github.io/mind-ar-js-doc/tools/compile/
2. Carregue `assets/images/torno-cnc-target.png`.
3. Compile a imagem.
4. Baixe o arquivo `.mind`.
5. Renomeie-o para `torno-cnc.mind`.
6. Coloque-o em `assets/targets/torno-cnc.mind`.

O projeto já está configurado para procurar exatamente esse arquivo.

## Publicação

Publique todo o conteúdo no GitHub e ative GitHub Pages em `main` + `/ (root)`.

## Observação

Os textos técnicos da aplicação são didáticos. A experiência não substitui manual de fabricante, treinamento de operação ou procedimentos de segurança de uma máquina real.
